☕ Coffee Stock

Sistema simples e moderno para controle de estoque de café, com suporte a quantidades fracionadas (ex: 2 + 3/4) e registro de movimentações.

Interface escura, leve e responsiva, ideal para uso interno.

🚀 Funcionalidades

✅ Controle manual de estoque

✅ Suporte a frações (1 + 1/4, 3/4, 2.75)

✅ Histórico de movimentações

✅ Interface moderna e responsiva

✅ Persistência com Firebase (Firestore)

✅ Tema dark por padrão

✅ Validação automática de entradas

📦 Tecnologias

React + TypeScript

Vite

Firebase (Firestore)

CSS puro (design system próprio)
